Ref methods​

MethodDescription
scrollToIndex(index)Scroll to a reel
play()Clear global pause
pause()Pause the active reel globally

MuteButton​

Optional pre-built mute toggle. Use it inside renderOverlay (or any child of FlashReels). You can also build your own with useFlashReels.
